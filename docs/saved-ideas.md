# Saved project ideas

## Chosen capstone contribution

Preserve one continuous weight history when a sheep’s RFID tag is replaced. Keep the animal’s permanent ID and associate the old and new tags with it. Test whether a weighing captured under the old tag while the scale was offline reaches the correct profile exactly once after the replacement and reconnection. [Prior art and evidence limits](sheep-farm-feature-research.md#indonesian-prior-art-for-connected-weighing-and-retagging--24-november-2026)

## Shortlisted farmer-app features

- **Body-condition prompt at weighing.** Use an animal’s weight history to prompt a hands-on condition check while it is still at the scale.
- **Indonesian voice notes.** Attach a spoken observation and farmer-confirmed follow-up to the current weighing.
- **Camera reading of the printed ear tag.** Suggest the visible ID for the operator to confirm when RFID fails.
- **Feed cost per kilogram gained by a pen.** Match feed expenditure and accepted weights for the same animals and period.
- **Age-aware comparison at weaning.** Show age and comparable peers alongside each lamb’s measured weight.

## Separate experiments and future work

- **Sheep face recognition.** Use a phone photo to retrieve an enrolled animal’s profile when a tag is unreadable or missing. The model may use the whole face. Start with Part 1 of the [University of Mysore dataset](https://data.mendeley.com/datasets/rb2z9mhkjj/1).
- **Sheep marketplace.** Build separately from the capstone.
